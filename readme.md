# 🏛️ bet.fund / Syndicate Profile Studio

A high-performance, luxury-themed profile customization studio and authenticated web portal for private banking and alternative investment syndicates. 

> **Note:** This repository contains the source code for the live web application. It is closed-source and intended solely for deployment.

---

## 🌐 Platform Architecture

* **Secure Auth Gateway:** Firebase-backed identity verification and sign-in handlers.
* **Handle Claim Registry:** Enforces unique username acquisition across the ecosystem.
* **Studio & Asset Pipelines:** Real-time transformation suite with Cloudflare R2 object storage integration for avatars and banners.
* **Prestige Badges:** Dynamic tiering and custom badge management.
